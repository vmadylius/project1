# Market Sessions Dashboard

This is a simple React application with three buttons representing major global trading sessions. When you click a button, details about that specific market session appear on the screen.

## Features

- Three session buttons (London, New York, Tokyo)
- Click event handling for dynamic content switching
- React `useState` hook implementation
- Clean, centered, and responsive layout

## Technologies

- React.js (Vite setup)
- JavaScript
- CSS3
